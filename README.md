# HPAI outbreaks and wild bird migration in Europe, 2015–2025

This repository contains the data and R code supporting analyses of the
spatiotemporal relationship between wild bird migration and highly pathogenic
avian influenza (HPAI) outbreaks in wild birds and poultry across Europe from
2015 to 2025.

The study examines whether HPAI outbreak occurrence, outbreak counts, and
outbreak timing vary in relation to region-specific wild bird migration onset
and migration intensity.

## Repository contents

### `data/`

Analysis-ready datasets used to reproduce the statistical analyses:

- `analysis_occurrence_wild.rds` – weekly NUTS3-level data used for the
  wild bird outbreak-occurrence model.
- `analysis_occurrence_poultry.rds` – weekly NUTS3-level data used for the
  poultry outbreak-occurrence model.
- `analysis_count_timing.rds` – data used to model weekly outbreak counts
  relative to migration onset.
- `analysis_count_intensity.rds` – data used to model associations between
  migration intensity and weekly outbreak counts.
- `analysis_first_detection.rds` – data describing first outbreak detection
  relative to migration onset.
- `region_lookup.rds` – geographic lookup table used to assign regions.
- `DATA_MANIFEST.csv` – description of the archived analysis datasets.
- `DATASET_DIMENSIONS.csv` – dimensions of the archived datasets.
- `MD5_CHECKSUMS.csv` – checksums for verifying file integrity.

### `HPAI_analysis.R`

R script used to reproduce the statistical analyses, validation procedures,
tables, and figures reported in the manuscript.

### `tables/`

Tables generated by the analysis workflow.


### `models/`

Saved statistical model objects, where applicable.

### `sessionInfo.txt`

R and package versions used for the final analyses.

## Main analyses

The analysis workflow includes:

1. Mixed-effects logistic regression models of weekly HPAI outbreak occurrence
   in wild birds and poultry.
2. Negative binomial mixed-effects models of weekly outbreak counts relative
   to migration onset.
3. Negative binomial mixed-effects models examining migration intensity and
   outbreak counts.
4. Models of the interval between migration onset and first outbreak detection.
5. Cox proportional hazards models of first outbreak timing.
6. Model validation and sensitivity analyses.

Analyses were conducted at the NUTS3 level using region-specific estimates of
wild bird migration onset and intensity.

## Data sources

The analysis integrates HPAI outbreak data from the World Organisation for
Animal Health (WOAH) WAHIS database with information derived from eBird Status
and Trends, poultry-density data from FAO Gridded Livestock of the World, and
environmental and geographic datasets.

Original source datasets remain subject to the licensing and terms of use of
their respective data providers.

## Reproducing the analyses

The analysis-ready datasets in `data/` are the canonical inputs for the final
analysis. Historical R workspaces used during development are not required.

To reproduce the analyses:

1. Download or clone this repository.
2. Open `R_code_HPAI.rmd`.
3. Set the repository/data directory if required.
4. Install the R packages listed in the script.
5. Run the script in numerical order.

The software environment used for the final analysis is recorded in
`sessionInfo.txt`.
